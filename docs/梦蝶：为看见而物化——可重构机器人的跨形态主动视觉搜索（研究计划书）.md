# 梦蝶：为看见而物化——可重构机器人的跨形态主动视觉搜索（研究计划书）

Nov 21, 2026 · @Tom

## 摘要

机器人能看到什么，很大程度上取决于它的身体：同一个藏在床底的目标，站着的四足机器人看不到，趴下的蛇形机器人一眼就能看到。本课题研究可重构机器人如何**为看见而改变身体**：在遮挡环境中搜索目标时，把"用哪种形态去看"与"往哪看"放在一起决策，并决定何时变、怎么变过去。

我们把形态切换建模为一种**信息采集动作**，提出"梦蝶"（MorphAction）框架。它分四步：先诊断当前为什么看不到目标（感知瓶颈）；再查各形态的"履历"，判断哪具身体能到达补救视点；然后在真正变形之前，从候选形态可达的相机位姿出发做显式的**跨形态想象**，估计每个候选动作的证据增益与代价；最后择优执行并验证。评估器不需要训练，只要给出新形态的履历，系统就能零样本使用它。

实验平台是由同构模块搭成的固定拓扑"超集机器人"。它通过关节锁定和接触角色分配实现六足、四足、人马形、蛇形、潜望等形态，底层采用经典步态加感知调制。我们预期证明三点：重构优于最好的固定形态，也优于连续姿态调节；系统能零样本用好训练时未见过的形态；增加测试时计算无法替代身体能力，即"思考替代不了身体"。

## 1 动机：为看见而物化

### 1.1 庄周梦蝶

《庄子·齐物论》写道："昔者庄周梦为胡蝶，栩栩然胡蝶也……此之谓物化。"庄周在梦里不是旁观一只蝴蝶，而是以蝴蝶的身体去感知世界；"物化"说的正是形态之间的转化。

这个故事给本课题提供了三个关键词：

- **物化**：机器人可以在不同形态之间转化，每种形态有自己的视角。
- **梦**：真正变形之前，先以另一具身体的视角"梦"一次，判断值不值得变。
- **梦醒之分**："不知周之梦为胡蝶与，胡蝶之梦为周与"提醒我们，想象出的观测绝不能当成真实证据。

### 1.2 身体决定"视点代价地形"

视觉是在对场景的光场采样。一张图像由相机位姿、视场、曝光、多相机之间的相对几何，以及视线上的遮挡物（包括机器人自己）共同决定。身体并不决定"能不能看"，而是决定每个视点的三件事：

- **能否到达**：可达的相机位姿集合。
- **成像质量**：抖动与运动模糊、距离决定的分辨率、自遮挡。
- **代价**：到达耗时、维持能耗、跌倒风险。

所以，一种形态就是一张**视点代价地形**：它让一片视点变得便宜而清晰，同时让另一片变得昂贵或不可达。重构，就是在不同的代价地形之间跳转。

已有证据表明，没有哪种身体能包打天下。一项搜索行为研究比较了三种相机高度：较高的相机整体视野更好，但当目标藏在地面的柜子里时，低相机反而更有利（[Learning Human Search Behavior from Egocentric Visual Inputs](https://arxiv.org/pdf/2011.03618)）。

需要强调的是，并非所有身体变化都算"重构"。连续调节机身俯仰、横滚或高度，已有工作研究过（见第 4 节），全关节可动的机器人本来就能做到。真正离散的重构来自三类变化：

1. **接触模式切换**：着地肢体的集合改变，例如四足站立、俯卧、前段抬起。
2. **刚度或驱动分配切换**：锁定部分关节，换来稳定的相机和更低能耗。
3. **拓扑或传感器布置切换**：模块对接，或相机换挂载点。

本课题以第一、二类为主，第三类留作扩展。

### 1.3 现有工作的空白

- **主动视觉与语义搜索**：身体固定，只决定相机往哪移、往哪看。
- **姿态与注视辅助感知**：利用连续姿态或学习注视方向，但不改变接触模式。
- **可重构机器人**：重构的目的几乎都是运动或通过性；少数感知驱动的系统依赖人工设计的构型库。

据我们的调研，还没有工作把**形态切换本身当作一种信息采集动作**，按当前信念决定何时变、变成哪种、怎么变过去。

## 2 核心问题、主张与研究问题

**核心问题：机器人应当何时、以及如何改变身体来看？**

**核心主张**：重构身体是一种信息采集动作。它抬高的是"能获得哪些证据"的上限，这是更多的思考、更好的视点规划都替代不了的。

本课题围绕三条可验证的主张展开：

- **C1 新问题与基准**：多形态主动视觉搜索。目标藏在需要不同身体才能看到的位置，机器人必须在形态之间切换才能高效完成任务。
- **C2 方法**：瓶颈与履历的分解，加上显式的跨形态想象。评估器免训练；只要给出新形态的履历，就能零样本使用它。
- **C3 实证结论**：重构优于最好的固定形态和连续姿态调节；系统能零样本用好未见过的形态；思考替代不了身体；并刻画切换在什么条件下值得。

四个研究问题对应题目中的三个子问题，其中"何时变、怎么变"拆成两个：

| 研究问题 | 对应子问题 | 假设 |
| --- | --- | --- |
| RQ1 当前该用哪种形态？ | 用哪种形态感知 | H1：先诊断感知瓶颈，再与形态履历匹配，比直接让大模型选形态、或按固定升级顺序选形态更准确、更省时 |
| RQ2 每种形态怎么看？ | 每种形态怎么感知 | H2：在经典步态上叠加感知调制（注视稳像、停顿时机、姿态偏移），就能让每种形态拿到可用的视觉证据，不必端到端学习运动控制 |
| RQ3 何时变？ | 何时变 | H3：比较各层动作的证据增益与代价来决定是否变形，优于"普通主动感知不够时再变形"的规则 |
| RQ4 怎么变过去？ | 怎么变过去 | H4：把过渡技能的耗时与成功率写进履历，并只在涉及切换时做两步前瞻，就足以避免代价过高或风险过大的切换 |

## 3 问题定义与适当简化

### 3.1 问题定义

**任务**：给定语言描述的目标（如"找到苹果"），机器人在未知的室内场景中搜索，直到获得满足要求的视觉证据，例如目标被检测到的置信度和图像分辨率都超过阈值。

**信念**：场景记忆包括占据地图、语义地图，以及目标位置假设的后验分布 p\_t(h)。

**形态**：形态集合为 𝓜。每种形态 m 有一份履历 R\_m，记录它的可达相机位姿、通过尺寸、速度、成像稳定性和过渡代价等（见 5.3 节）。

**动作分三层**：

- **视点层**：在当前形态内移动、转向、调整注视。
- **注意力层**：裁剪、放大、回看已有图像，不需要身体运动。
- **形态层**：切换到另一种形态，代价和成功率来自履历。

**目标**：以最短的期望时间获得所需证据，同时惩罚跌倒和过渡失败。时间包括思考时间。

```latex
\min_{\pi}\ \mathbb{E}\big[\,T_{\text{evidence}} + T_{\text{think}} + \lambda_F\,\mathbb{1}[\text{fall}]\,\big]
```

### 3.2 适当简化

这里借鉴 Learning to Reconfigure 的经验：问题形式化可以大胆简化，但不能简化掉让问题成立的那部分。

| 必须保留（否则问题坍缩） | 可以简化（不影响创新） |
| --- | --- |
| 形态之间互补：每种形态都是某类藏匿位置唯一高效的观察方式 | 固定拓扑，不做模块对接 |
| 需要看哪里取决于已经看到了什么 | 形态模板由人给定，具体参数通过测量和调节确定 |
| 过渡有真实的时间代价和失败风险 | 底层采用经典步态加感知调制（L1） |
| 存在强基线：固定形态加连续姿态调节，使用同一个决策闭环 | 静态场景、单个目标、目标类别已知 |
| 想象只能使用机器人自己的场景记忆，不能读取仿真器的真实场景 | 观测用深度图加语义掩码（仿真真值叠加噪声），RGB 作为可选项 |

## 4 相关工作与定位

本课题的每个组成部分都有前人工作，新颖性来自它们的交汇点：**把形态切换当作感知动作，并且由感知瓶颈驱动、靠履历实现零样本泛化**。

| 方向 | 代表工作 | 与本课题的关系 |
| --- | --- | --- |
| 主动感知与下一最佳视点 | [Bajcsy 等, 2018](https://arxiv.org/abs/1603.02729)；[GauSS-MI](https://arxiv.org/abs/2504.21067) | 决定传感器往哪移，但身体固定 |
| 语义目标搜索 | [VLFM](https://arxiv.org/abs/2312.03275) | 用视觉语言模型生成语义价值地图，是我们语义先验的来源；身体固定 |
| 姿态与注视辅助感知 | [腿式机器人姿态感知探索](https://arxiv.org/pdf/2609.19460)；[LEAP](https://arxiv.org/pdf/2609.17628) | 利用连续的俯仰、横滚或学习注视方向；构成我们的强基线 |
| 可重构机器人 | Learning to Reconfigure（ICML 2026）；[Pathak 等, 2019](https://arxiv.org/abs/1902.05546)；[DittoGym](https://arxiv.org/abs/2401.13231)；[Daudelin 等, 2018](https://arxiv.org/abs/1709.05435) | 重构的目的是运动或通过性；感知驱动的系统依赖人工构型库 |
| 信念空间规划与大模型规划 | [Kaelbling & Lozano-Pérez, 2013](https://dspace.mit.edu/handle/1721.1/87038)；[LLM3](https://arxiv.org/abs/2403.11552)；[VLM-TAMP](https://arxiv.org/pdf/2410.02193)；[LLM-Modulo 系统研究](https://www.arxiv.org/pdf/2510.00182) | 感知型规划和"大模型提议、模型验证"都已有先例；我们采用更简单的贪心闭环 |
| 想象与测试时扩展 | [GenEx](https://arxiv.org/abs/2411.11844)；[MindJourney](https://arxiv.org/abs/2507.12508)；[RoVer](https://arxiv.org/html/2510.10975v2) | 用生成式世界模型想象或用验证器挑选动作；我们以显式几何想象为主，并坚持梦醒分离 |
| 基于能力的任务分配 | [STRATA](https://arxiv.org/abs/1903.05149) | 按能力向量匹配机器人与任务，因此"履历匹配"本身不新；我们的新意在单体内的动态切换，且由视觉瓶颈驱动 |
| 自适应次模优化 | [Golovin & Krause, 2011](https://arxiv.org/abs/1003.3967) | 自适应贪心在满足自适应次模性时接近最优，是贪心闭环的理论依据 |

**与最接近工作的区别：**

- 与 **Learning to Reconfigure** 相比：目标从"走得更远"变成"看得到"；回报取决于信念且边际递减；切换由感知瓶颈触发，而不是按固定周期调度。
- 与 **VLFM、LEAP、姿态感知探索**相比：它们只在一具身体内优化视点；我们把"换一具身体"纳入决策。
- 与 **GenEx、MindJourney** 相比：它们用生成模型想象画面；我们主要在场景记忆中做几何想象，只把生成式想象作为可选的复核手段，并且从不让想象的观测进入记忆。

## 5 方法：梦蝶（MorphAction）框架

### 5.1 总体闭环：提议、想象、择优

框架是一个每步重新决策的闭环，不需要符号规划器。每一轮依次经过五个模块：

1. **证据需求解析**：把任务描述转成需要的证据，例如"苹果在图像中可识别，置信度不低于阈值"。
2. **感知瓶颈诊断**：判断当前为什么还没拿到证据，以及哪些补救视点能解决问题。
3. **动作提议**：按固定模板做结构化思维链推理，给出少量候选动作，覆盖视点层、注意力层和形态层。
4. **跨形态想象评估**：在场景记忆中，从候选动作对应的相机位姿出发"做梦"，估计证据增益和代价。
5. **执行与验证**：执行得分最高的动作，检查是否拿到真实的新证据，然后更新记忆。

记忆分三部分：场景记忆（占据地图、语义地图、未观测区域、目标假设）、情景记忆（动作与观测历史、失败案例），以及形态履历。

**梦醒分离**是贯穿全框架的规则：第 4 步想象出的观测只用于选择动作，绝不写进场景记忆；只有第 5 步验证过的真实观测才能更新信念。

### 5.2 平台：模块化超集机器人与候选形态

用同构模块搭成一个固定装配体，例如：4 节脊柱模块（节间有偏航和俯仰两个自由度），3 对各有 3 个自由度的腿，前端一个头部模块，带深度相机和颈部的俯仰、偏航自由度。装配体不再对接或分离。

每种形态由三样东西定义：哪些关节锁定、锁在什么角度，以及**哪些肢体着地**。候选形态如下（相机高度为粗估，最终由测量给出）：

| 形态 | 独特的视觉生态位 | 感知运动协调的难点 |
| --- | --- | --- |
| 六足 | 中等高度，最稳，可以边走边看 | 如何利用稳定性连续扫视；前腿的自遮挡 |
| 四足 | 中等高度，转场最快 | 小跑抖动大，需要"跑过去、停下看"的节奏 |
| 人马形 | 视点高，上身可以独立转动注视 | 下身行走时保持上身稳定；颈部注视与腿部的协调 |
| 蛇形 | 最低、最窄，能进床底和沙发下 | 头部随身体摆动，需要主动稳像；视野贴地 |
| 潜望 | 身体留在狭窄处，头部抬起局部扫视 | 抬头时支撑面小；扫视幅度与倾覆风险的权衡 |
| 直立双足（可选） | 视点最高 | 训练难度最大；只有当高处藏匿位置无法被覆盖时才加入 |

**形态筛选流程**：先提出候选模板，再在仿真中测出每个模板的履历，最后选出能覆盖所有藏匿类型、冗余最小的子集。逐一去掉某种形态、观察性能下降多少，本身就是一组实验。

### 5.3 形态履历

履历是高层看到每具身体的**唯一接口**，相当于一个压缩的身体模型。正因为高层只通过履历认识形态，给出新形态的履历就能零样本使用它。

| 字段 | 含义 | 获取方式 |
| --- | --- | --- |
| 可达相机位姿 | 相机高度范围、俯仰与偏航范围 | 运动学采样，加稳定性检查 |
| 通过尺寸 | 最小离地间隙、最小宽度 | 由包络体计算 |
| 移动速度 | 各步态的平均速度 | 物理仿真测量 |
| 成像稳定性 | 抖动幅度与速度、步态相位的关系 | 物理仿真测量 |
| 注视自由度 | 注视能否与行走解耦 | 由结构决定 |
| 自遮挡 | 视野中被自身遮挡的区域 | 渲染测量 |
| 过渡 | 切换到其他形态的耗时与成功率 | 物理仿真中反复测试 |
| 能耗与风险 | 单位时间能耗、跌倒概率 | 物理仿真测量 |

### 5.4 每种形态的感知运动协调（L1）

底层不从零学习运动控制，而是在经典步态之上叠加感知调制：

- **步态**：每种形态使用中枢模式发生器（CPG）或脚本步态，例如六足三足步态、四足小跑、蛇形蜿蜒。
- **统一的感知调制接口**：所有形态共享一组低维调制量，包括注视目标、移动速度、是否停顿、机身姿态偏移。形态之间的差异由步态层吸收。
- **稳像**：用运动学求解注视方向，再根据预测的机身运动做前馈补偿，类似生物的前庭眼动反射。
- **取景时机**：停下再看，或在步态的平稳相位取景。
- **到达视点**：采样规划或模型预测控制。
- **形态过渡**：关键帧序列加 PD 控制；在物理仿真中测出耗时和成功率，写进履历。

强化学习不是必需的，只用于解析方法难以处理的环节，例如蛇形在不平地面上稳住头部、人马形抬起上身时保持平衡。如果使用学习，就训练一个以形态为条件、在上述低维调制量上输出的共享策略。

### 5.5 感知瓶颈诊断

一个目标能被看见并识别，需要同时满足五个可见性条件。对我们的问题，还要加上第六个：补救视点是否可达。每个条件不满足，就对应一类瓶颈和首选的补救层级：

| 可见性条件 | 不满足时的瓶颈 | 首选补救 |
| --- | --- | --- |
| 视线无遮挡 | 遮挡 | 视点层；补救视点不可达时转形态层 |
| 目标在视场内 | 视场 | 视点层：转向、调整注视 |
| 分辨率足够 | 尺度 | 注意力层：裁剪放大；或视点层：走近 |
| 视角合适 | 视角 | 视点层：换个角度 |
| 成像质量够好 | 模糊或抖动 | 感知运动层：停顿、稳像 |
| **补救视点在当前形态可达集内** | **可达性** | **形态层：切换到能到达的形态** |

**形态层动作的触发条件**：补救视点不在当前形态的可达集内，或者在另一种形态下代价低得多。这是一个可以在场景记忆上计算的几何检查，比"普通主动感知不够时再变形"更有原则。

**实现方式**：前四个条件和可达性用几何方法在场景记忆上计算；视觉语言模型补充语义线索，例如"桌布垂下，桌下可能被挡住"。输出是一条结构化记录：瓶颈类型、涉及区域、补救视点集合。

### 5.6 跨形态想象评估器（梦）

评估器给每个候选动作打分。对形态 m 和候选视点 v，期望证据增益写成：

```latex
\text{Gain}(m, v) \approx \sum_{h} p_t(h)\cdot P\big(\text{可见且可识别} \mid v, m, h\big) \;-\; \lambda \cdot \text{Cost}(m, v)
```

- **p\_t(h)**：目标在各处的概率，来自场景记忆和视觉语言模型的语义先验。
- **P(可见且可识别)**：从候选相机位姿在场景记忆中做光线投射或渲染算出，再叠加履历中的分辨率与抖动模型。
- **Cost**：直接查履历，包括耗时、切换代价和风险。

这个分解让**零样本使用新形态来自结构本身，而不是来自训练**：给出新形态的履历，评估器就能直接计算。

想象分三层，按需升级：

| 层级 | 做法 | 成本 | 何时使用 |
| --- | --- | --- | --- |
| 第 0 层：几何想象 | 在场景记忆中从候选相机位姿做光线投射 | 毫秒级 | 每个候选都算 |
| 第 1 层：结构先验 | 根据家具类别和可见的下沿，估计未知区域的离地间隙与内部空间 | 很低 | 候选依赖未知区域时 |
| 第 2 层：生成式想象（可选） | 用世界模型补出画面，交给视觉语言模型判断能否看到目标 | 高 | 只在决策胶着且涉及形态切换时；作为扩展和消融 |

第 1 层是关键。未知区域里，影响决策的往往不是"长什么样"，而是"空间有多大、哪具身体能进去、进去后视线是否通畅"，这类问题不需要生成像素。

**防止被评估器误导**：对依赖未知空间的部分取保守估计（置信下界），避免挑中被过度乐观评分的候选。评估器只有极少数低维参数，例如代价权重 λ 和抖动模型系数，并且只在验证集上拟合。

### 5.7 决策与测试时计算

- **提议**：结构化思维链按"需要什么证据 → 为什么没看到 → 补救在哪一层 → 当前形态能否到达"的模板推理，采样 4 到 8 个候选。
- **选择**：每步重新决策的贪心。只有候选中出现形态切换时，才做两步前瞻；思考时间计入任务耗时。
- **理论依据**：如果问题满足自适应次模性，自适应贪心就有接近最优的保证（[Golovin & Krause, 2011](https://arxiv.org/abs/1003.3967)），而缩小目标位置假设正是这类问题的典型例子。加入切换代价后保证会失效，这是后续理论工作的切入点。
- **自适应计算分配**：前几名候选的得分差距越小、涉及的切换代价越大，就分配越多的采样和越深的前瞻，也就是"变形之前多想想"。

### 5.8 大模型分工

原则：大模型负责慢的、语义的、可容错的提议；数值、几何和可行性交给模型计算和验证。大模型不进入控制回路，也不独自做最终决策。

| 模块 | 实现 | 理由 |
| --- | --- | --- |
| 证据需求解析 | 开源大语言模型 | 理解语言任务 |
| 瓶颈诊断 | 视觉语言模型提供语义线索，几何计算判断可见性和可达性 | 语义线索适合大模型；可见性可以直接算 |
| 动作提议 | 视觉语言模型做结构化思维链，几何采样器给出连续参数 | 大模型提议，几何保证可行 |
| 证据增益评估 | 几何想象加结构先验加履历，不用大模型 | 需要校准过的数值 |
| 执行验证 | 开发时用仿真真值加噪声，最终评估用开放词汇检测器或视觉语言模型 | 控制成本，同时检验真实模型 |
| 情景记忆（可选） | 参考 [Reflexion](https://arxiv.org/abs/2303.11366)，把失败反馈写成文字经验存入记忆 | 部署时在线改进，无需训练 |

所有大模型都使用开源模型，部署在 A100 上低频调用。

## 6 实验设计

### 6.1 仿真平台与任务

- **仿真器**：[MuJoCo Warp](https://github.com/google-deepmind/mujoco_warp) 在 A100 上并行仿真，并用自带的 GPU 批量渲染器输出深度和分割图。Isaac Sim 的渲染不支持 A100 这类没有 RT 核心的 GPU（[NVIDIA 论坛说明](https://forums.developer.nvidia.com/t/gpu-requirement/305727/2)），因此不选。MacBook 用于开发和调试，A100 用于大规模运行。
- **场景**：自写 MJCF 参数化家具生成器，生成床、沙发、桌、柜、书架等，离地间隙和内部空间可控。必要时引入 Infinigen 可动家具，它支持导出 MJCF（[导出文档](https://infinigen.cs.princeton.edu/docs/latest/ExportingToSimulators.html)）。
- **观测**：深度图加语义掩码（仿真真值叠加噪声）；RGB 作为可选项。
- **藏匿类型**：低矮缝隙（床底、沙发底）、高处（柜顶、台面深处）、遮挡物之后（沙发背后、箱子后）、柜内低层开放格、远处的小目标。每类藏匿位置都应有一种形态是唯一高效的观察方式。

### 6.2 基线

| 基线 | 检验什么 |
| --- | --- |
| 最佳固定形态，使用同一个决策闭环 | 重构是否必要 |
| 固定形态加连续姿态与注视调节，使用同一个决策闭环 | 强基线：离散重构是否优于连续姿态调节 |
| 固定升级规则：视点层 → 注意力层 → 形态层 | 由证据增益决定何时变形是否优于固定规则（H3） |
| 纯思维链智能体：视觉语言模型直接选动作 | 几何想象评估是否必要 |
| VLFM 式语义前沿探索（固定形态） | 与现有语义搜索方法比较 |
| 理想形态选择（上界） | 离最优还有多远 |
| 训练版评估器 | 免训练能否追平训练 |

### 6.3 指标

- 成功率；获得所需证据的时间（含思考时间）。
- 路径长度、能耗、形态切换次数。
- 跌倒率、过渡失败率。

每项结果报告至少 8 个随机种子的中位数与四分位距。跨任务汇总时报告逐任务结果和几何平均，避免少数数值大的任务主导结论。

### 6.4 关键实验

1. **E1 主对比**：在全部藏匿类型上，与 6.2 节的所有基线比较。
2. **E2 零样本新形态**：开发全程留出一种形态，测试时只提供它的履历，检验系统能否正确选用并用好它。
3. **E3 思考与身体的扩展曲线**：改变采样数和前瞻深度，画出不同形态库规模下"性能随计算预算变化"的曲线。预期固定身体的曲线很快到顶，而增加形态会抬高上限。
4. **E4 切换何时值得**：按藏匿类型、距离和切换代价分组，分析什么条件下变形带来净收益。
5. **E5 消融**：去掉瓶颈诊断、去掉第 1 层结构先验、去掉两步前瞻、违反梦醒分离（让想象的观测写入记忆）、加入第 2 层生成式想象。

### 6.5 数据划分协议

为防止提示词和参数过拟合开发场景：

- **开发集**：只用于设计提示词和模块；进入验证阶段前冻结提示词。
- **验证集**：只用于拟合少数低维参数。
- **测试集**：使用未见过的房间布局、家具类别和目标类别，并完全留出一种形态。

程序化生成器让这种划分很容易实现，可以按生成参数而不只是随机种子来切分。

### 6.6 物理有效性检查

所有底层技能都在物理仿真中运行和测量，履历中的数值来自实际执行，而不是人工设定。真机验证不在本轮范围内，留作后续工作。

## 7 预期贡献

1. **新问题**：把"何时、如何改变身体来看"形式化为多形态主动视觉搜索，把形态切换建模为信息采集动作。
2. **新方法**：瓶颈与履历的分解，加上显式的跨形态想象和梦醒分离；评估器免训练，靠履历零样本使用新形态。
3. **新基准**：可重构机器人的多形态视觉搜索任务套件、程序化场景生成器和评价协议。
4. **实证结论**：重构身体扩展的是可获得证据的上限，思考替代不了身体；并给出切换值得与否的条件。

## 8 风险与应对

| 风险 | 应对 |
| --- | --- |
| 距 ICML 2027 截稿只有约 9 周 | 严格按最小可行系统推进；先用三种形态（四足、蛇形、人马形）跑通全流程，再补齐其余形态 |
| 多形态底层实现量大 | 坚持 L1：经典步态加感知调制，不做端到端运动学习 |
| 几何想象在未知区域不准 | 第 1 层结构先验加保守打分；生成式想象只用于复核 |
| 重构的收益被连续姿态调节抵消 | 设为强基线；若收益确实有限，结论转为刻画"何时重构值得" |
| 提示词和参数过拟合开发场景 | 执行 6.5 节的数据划分协议，提前冻结提示词 |
| 大模型推理延迟 | 低频调用、缓存结果，并把思考时间计入任务耗时 |
| 步态质量不佳影响结论 | 履历如实测量，结论建立在同一底层上的相对比较 |
